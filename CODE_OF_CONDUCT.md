# Code of Conduct

This project follows the
[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be kind, assume good faith, and keep discussion about the work.
Harassment isn't tolerated.

To report a problem, use a private
[security advisory](https://github.com/Arnav717/oryn/security/advisories/new)
or contact the maintainer through their GitHub profile.
