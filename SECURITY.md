# Security

oryn handles API tokens, runs commands on your machine and starts AI agents, so
security reports are very welcome.

**Please don't open a public issue.** Report it privately through
[GitHub's security advisories](https://github.com/Arnav717/oryn/security/advisories/new)
with steps to reproduce. Expect a first reply within a week.

Things that matter most here: a way to run commands through text oryn displays
or passes on, a token reaching a log, error or screen, prompt injection through
GitHub or deploy data, and a way past a confirmation before a deploy or delete.
